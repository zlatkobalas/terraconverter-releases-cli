# TerraConverter CLI — Releases

Download-only repository for the **TerraConverter CLI**, the command-line version of TerraConverter, a coordinate-conversion tool between Croatian and global coordinate systems (WGS84, HDKS, MGI 1901, HTRS96/TM, UTM/UPS, MGRS, ECEF, Plus Code, Geohash).
This repository contains **no source code** — only compiled builds, published under [Releases](../../releases). The application is closed-source freeware for non-commercial use; see [`LICENSE.md`](LICENSE.md) (English, canonical) or [`LICENSE.hr.md`](LICENSE.hr.md) (Croatian).

Looking for the desktop GUI or the Android app instead? See
[terraconverter-releases-desktop](https://github.com/zlatkobalas/terraconverter-releases-desktop)
or [terraconverter-releases](https://github.com/zlatkobalas/terraconverter-releases).

## Downloads

- **Windows CLI** (`TerraConverter_CLI_vX.Y.Z_windows.zip`) — standalone command-line tool, no installation, no admin rights. Extract anywhere and run `TerraConverter_CLI.exe` (or add the extracted folder to PATH). See the included `README.md`/`USAGE.md` for setup and the full command reference.
