# TerraConverter CLI — Izdanja

Repozitorij isključivo za preuzimanje **TerraConverter CLI-ja**, naredbeno-redne verzije TerraConvertera, alata za pretvorbu koordinata između hrvatskih i globalnih koordinatnih sustava (WGS84, HDKS, MGI 1901, HTRS96/TM, UTM/UPS, MGRS, ECEF, Plus Code, Geohash).
Ovaj repozitorij **ne sadrži izvorni kod** — samo gotove izgradnje, objavljene pod [Releases](../../releases). Aplikacija je zatvoreni freeware za nekomercijalnu upotrebu; vidi [`LICENSE.hr.md`](LICENSE.hr.md) (hrvatski prijevod) ili [`LICENSE.md`](LICENSE.md) (engleski, mjerodavan).

Tražiš desktop GUI ili Android aplikaciju? Vidi
[terraconverter-releases-desktop](https://github.com/zlatkobalas/terraconverter-releases-desktop)
ili [terraconverter-releases-android](https://github.com/zlatkobalas/terraconverter-releases-android).

## Preuzimanja

- **Windows CLI** (`TerraConverter_CLI_vX.Y.Z_windows.zip`) — samostalan naredbeno-redni alat, bez instalacije, bez admin prava. Raspakiraj bilo gdje i pokreni `TerraConverter_CLI.exe` (ili dodaj raspakiranu mapu u PATH). Vidi priloženi `README.md`/`USAGE.md` za postavljanje i potpuni referentni pregled naredbi.
